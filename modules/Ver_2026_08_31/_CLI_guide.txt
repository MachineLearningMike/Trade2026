================================================================================
CLI GUIDE — modules/Ver_2026_08_30
Remember verbs, not 60 flags. Defaults come from config.py when omitted.
================================================================================

Run from this directory (or put it on PYTHONPATH), with your torch env active.

  python TRAIN.py <command> [shared flags] [command flags]


--------------------------------------------------------------------------------
1. DAILY CHEAT-SHEET
--------------------------------------------------------------------------------

  python TRAIN.py train --model regression --label rise_flag --epochs 12
  python TRAIN.py infer --label rise_flag --test 32
  python TRAIN.py validate --latest --slice 0:30
  python TRAIN.py ensemble --label yield --delays 0,2,5,10
  python TRAIN.py error-ensemble --label yield --stages 3 --clean
  python TRAIN.py plot --history
  python TRAIN.py plot --loss
  python TRAIN.py report              # → _save/YYYYMMDD_HHMMSS/ + git commit
  python TRAIN.py report my_run
  # NOT: train report  (two verbs; CLI now redirects to report with a hint)

  # one-off config override without editing config.py
  python TRAIN.py train --label yield --set patch_size=15 --set num_layers=6

  # rare
  python TRAIN.py search --model vae
  python TRAIN.py tools compare --vae-key K1 --yield-key K2
  python TRAIN.py tools viz-trend
  python TRAIN.py tools viz-features
  python TRAIN.py tools yield-windows


--------------------------------------------------------------------------------
2. COMMANDS (verbs)
--------------------------------------------------------------------------------

  train            Train one (model, label) cell
  infer | test     Test-set evaluation
  validate         Checkpoint validation (best or latest)
  ensemble         TelePred delay bank (one checkpoint per delay)
  error-ensemble   Residual ErrorEnsemble stages
  plot             History / loss / validation curves (no market reload for
                   history/loss; uses checkpoint artifacts)
  report           Batch-export validation + history plots under _save/<name>/,
                   plus report.text with the active label's metric slots
                   (val + test). Omit name → datetime folder YYYYMMDD_HHMMSS and
                   git-commit all current changes with that message
                   (use --no-commit to skip)
  search           Hyperparameter search (alias: sweep)
  tools            Rare utilities (compare, viz, yield-windows)

  python TRAIN.py --help
  python TRAIN.py train --help
  python TRAIN.py plot --help


--------------------------------------------------------------------------------
3. SHARED FLAGS (most commands)
--------------------------------------------------------------------------------

  --model / --model-type     regression | vae
  --label                    trend | yield | latent | rise_flag | none
  --yield-target             both | chance | near   (when --label yield)
  --latent-dist              normal | student       (when --label latent)

  --epochs N                 planned epochs (train / ensemble / error-ensemble)
  --extend N                 adjust planned epochs (+/−)
  --clean                    wipe current checkpoint key (or ensemble stages)

  --delay D                  single TelePred delay (bars)
  --delays LIST              e.g. 0,2,5,10
  --checkpoint KEY           force checkpoint folder name

  --past / --future          past_window / future_window (bars)
  --batch                    batch_size

  --set KEY=VAL              repeatable escape hatch into config
                             (e.g. --set rise_flag_decision_threshold=0.6)

Omitted flags → values from config.py.


--------------------------------------------------------------------------------
4. PER-COMMAND FLAGS
--------------------------------------------------------------------------------

train
  --save-every M             checkpoint every M minutes
  --no-validate              disable train-time validation

infer / test
  --test [N]                 all test samples if bare; N spaced samples if given
  --no-viz                   skip interactive plots
  --checkpoint KEY

validate
  --best                     use best_val checkpoint (default)
  --latest                   use latest checkpoint
  --slice V | V1:V2          percent slice of sorted val samples
  --checkpoint KEY

ensemble
  --delays 0,2,5,10
  --epochs / --extend / --clean
  --save-every M

error-ensemble
  --stages N                 total stages (error_ensemble_n)
  --extend-stages N          add N stages after finished ones
  --epochs / --clean
  --save-every M
  Point labels only: trend | yield | rise_flag  (not latent / vae)

plot
  --history [KEY|all]        training history (default KEY=current)
  --loss [KEY|all]           latest-epoch minibatch loss
  --validation [E …]         saved val curves for epoch E (optional slice)
  --checkpoint KEY

report
  report [DIR]               or: report --out DIR
                             omit DIR → _save/YYYYMMDD_HHMMSS/ + git commit
                             (message = folder name; same idea as error_ensemble_report)
                             Always writes report.text from the active label's
                             metric slots (validation + test sections).
  --ensemble                 export for every TelePred delay (ensemble-report)
  --no-commit                with bare report, skip the auto git commit

search  (alias: sweep)
  --epochs-per-trial N
  --search-extend N          (alias --sweep-extend)
  --with-delays              hparam grid × full delay bank
  --model vae                VAE search (replaces old --vae-sweep)

tools
  tools compare --vae-key K1 --yield-key K2 [--slice V|V1:V2]
  tools viz-trend
  tools viz-features
  tools yield-windows [--n N]


--------------------------------------------------------------------------------
5. TYPICAL WORKFLOWS
--------------------------------------------------------------------------------

A. Train a rise_flag binary classifier, then test
  1) Edit config.py if needed (label, windows, threshold, …)
  2) python TRAIN.py train --label rise_flag --epochs 12
  3) python TRAIN.py infer --label rise_flag
     Metrics (TP/TN/FP/FN, …) come from the label; threshold from
     config rise_flag_decision_threshold (default 0.5).

B. Resume / add epochs
  python TRAIN.py train --label rise_flag --extend 5
  (epochs is NOT part of the label-cache key; labels should reload from pickle)

C. Yield regression + TelePred bank
  python TRAIN.py ensemble --label yield --yield-target near --delays 0,2,5,10

D. Residual ErrorEnsemble
  python TRAIN.py error-ensemble --label yield --stages 3 --clean
  python TRAIN.py error-ensemble --label yield --extend-stages 2
  # Report (members + en_k label metrics / TP-TN-FP-FN for rise_flag):
  python error_ensemble_report.py
  # Also writes label_metrics_member_vs_ensemble.png (2xn series: member vs en).
  # RiseFlag decision threshold: config rise_flag_decision_threshold (default 0.5).
  # Note: logic txt is Yield/MSE-oriented; rise_flag residual ensembling is experimental.

E. Inspect training
  python TRAIN.py plot --history
  python TRAIN.py plot --loss
  python TRAIN.py plot --validation
  python TRAIN.py report              # datetime folder under _save/ + commit
  python TRAIN.py report my_run       # named folder, no auto-commit

F. VAE (unsupervised)
  python TRAIN.py train --model vae --label none --epochs 12
  (vae coerces label→none if you forget)


--------------------------------------------------------------------------------
6. PRODUCT MATRIX (COMPAT)
--------------------------------------------------------------------------------

  (regression, trend)
  (regression, yield)        + --yield-target both|chance|near
  (regression, latent)       + --latent-dist normal|student
  (regression, rise_flag)    binary classifier
  (vae, none)                unsupervised recon+KL

Unsupported pairs fail fast (see registry.py / compat.py).


--------------------------------------------------------------------------------
7. CONFIG vs CLI
--------------------------------------------------------------------------------

  Source of truth for defaults:  config.py
  CLI overrides only what you pass.
  One-off keys without a dedicated flag:  --set KEY=VAL

  Examples:
    --set patch_size=15
    --set num_layers=6
    --set rise_flag_decision_threshold=0.6
    --set learning_rate=0.00001
